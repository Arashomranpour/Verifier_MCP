VerifierMCP

An MCP server that gives any LLM the power to check its own work. Five verification tools — symbolic math, sandboxed code, JSON-Schema, units, regex — callable from Claude Desktop or any MCP client. This page runs the exact same tools so you can watch them catch errors live.

# Connect to Claude Desktop (claude_desktop_config.json)
"mcpServers": { "verifier": { "command": "python", "args": ["-m", "verifier_mcp.server"] } }

verify_math SymPy

Catches the classic (x+1)² = x²+1 mistake — checks algebra symbolically.

run_code sandbox

Runs Python in an isolated subprocess and returns the real output.

validate_schema JSON Schema

Confirms structured output actually conforms — here age must be an integer.

check_units Pint

Dimensional analysis — evaluate a quantity and check it matches an expected unit.

test_regex re

Proves a regex matches what it should and rejects what it shouldn't, with capture groups.

Model Context Protocol · stdio + streamable HTTP · deployable via Amazon Bedrock AgentCore Gateway
